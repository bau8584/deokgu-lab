# 주석·강조 작업 지침

"이 폴더 스샷에 주석/강조 달아줘" 요청을 받거나, 캡처 직후 이어서 수행한다.

## 도구
- Python + Pillow로 그린다. 한글 라벨이 깨지지 않도록 **한글 지원 폰트**를 쓴다
  (Noto Sans KR 또는 Pretendard). 없으면 설치한다 (예: `apt-get install -y fonts-noto-cjk`).
- **원본은 보존**한다. 결과는 `<원본이름>-annotated.png`로 따로 저장한다.
- 원본 해상도(2x)를 유지해 선명도를 잃지 않는다.

## 비주얼 톤앤매너 (박덕구쌤 브랜드, 고정)
- 무드: **밝고 유쾌하게 시선 끌기.** 또렷하되 공격적이지 않게, 따뜻한 강조.
- 강조색: 메인 `#F2A33C`(치즈 오렌지), 포인트 `#3CC9A0`(민트). 텍스트는 흰색 또는 차콜 `#2E2A26`.
- 화살표: 두께 8px, 큰 화살촉, 둥근 끝. 도드라지되 부드럽게.
- 강조 박스: 라운드 사각형 테두리 6px(치즈 오렌지). 필요 시 바깥을 25% 어둡게(스포트라이트).
- 라벨 칩: 치즈 오렌지 채움 + 흰 글씨 + 둥근 모서리. 핵심 1개는 민트로 변주 가능.
- 번호 배지: 원형 치즈 오렌지 배경에 흰 숫자.
- 시그니처: 가끔 한 컷에 치즈냥 스티커를 작게 얹어도 좋다(과하지 않게, 중간 노출).

## 라벨 텍스트
- **짧은 설명형**으로 쓴다. 예: "탭 한 번으로 기록", "실시간으로 점수 반영", "1초 만에 팀 편성".
- 한 라벨은 12자 내외. 기능의 *가치*를 한 줄로.

## 규칙
- 이미지당 강조 포인트는 **1~3개**만. 과하게 달지 않는다(시선 분산 방지).
- 강조할 위치와 라벨 문구를 먼저 목록으로 제안하고, 사용자 확인 후 그린다.
- 학생 이름 등 개인정보가 보이면 같은 작업에서 블러 처리한다.

## 정리
- README 인덱스에 주석본(`-annotated.png`) 행도 추가한다.
- 끝에 처리한 장수와 각 이미지에 단 라벨 문구를 요약 보고한다.

# 소개 글 작업 지침

"이 앱/이 폴더로 소개글 써줘" 요청을 받으면 수행한다.

## 입력 파악
- 앱 소스가 있으면 읽어 핵심 기능과 *해결하는 문제*를 파악한다.
- `shots/` 폴더에 캡처·주석본이 있으면, 어떤 화면을 글에 붙일지 매칭한다.
- 불명확하면 한두 가지만 사용자에게 확인한다. **없는 기능은 지어내지 않는다.**

## 스타일 (박덕구쌤 페르소나, 고정)
- 화자: **박덕구쌤** — "옆 반에 늘 뭔가 만드는 유쾌한 쌤." 밝고 친근, 가끔 셀프 디스
  유머("또 만들었습니다… 누가 말려요 😅"). 가르치려 들지 않고 선물처럼 툭 건넨다.
- 톤: 후킹은 살리되 **따뜻하게.** 짧은 문장, 줄바꿈 시원하게, 스크롤하며 스캔되게.
  과장 광고 금지 — 효과는 솔직하게.
- 독자: **동료 초등교사.** 모든 가치를 "교실에서 뭐가 줄어드나 / 수업이 어떻게
  편해지나"로 번역한다. ("손 덜 가는 교실" — 교사 본인이 얼마나 편해지는지를 가치로)
- 이모지·해시태그 적극 사용(과하지 않게). 치즈냥 🐈을 가끔 시그니처로.
  기본 해시태그(앱에 맞게 가감): #초등교사 #교실수업 #수업나눔 #에듀테크 #박덕구쌤
- 마무리 시그니처(선택): "만드는 재미로 사는 초등쌤, 박덕구 🐈"

## 구조 (어텐션 공식)
1. **훅** — 첫 줄에서 공감/문제 찌르기 (예: "○○하느라 쉬는 시간 또 날아갔죠? 😮‍💨")
2. **비포 → 애프터** — 원래 이렇게 번거롭던 게 → 이렇게 바뀐다
3. **핵심 기능 2~3개** — 각 한 줄, 기능이 아니라 *가치* 중심
4. **CTA** — 써보기 링크 / "저장해두세요" / "동학년쌤 태그하기"

## 출력 — 3가지 버전을 한 번에
- **인스타·틱톡 캡션**: 가장 짧고 후킹 강하게. 첫 1~2줄에서 승부. 줄바꿈·이모지·해시태그 풀로.
- **포트폴리오·블로그**: 중간 길이. 맥락 + 기능 + 스샷 배치 제안(`[01-home.png]` 위치 표시).
- **초등교사 사이트**: 정보 충실형. 어떤 학년·교과·수업 상황에서 쓰면 좋은지까지.
  이 버전만 후킹을 살짝 눌러 **신뢰감 있게** 쓴다.

## 정리
- 결과는 `shots/<해당폴더>/copy.md`로 저장하고, 세 버전을 헤더(`## 인스타`, `## 블로그`,
  `## 교사 사이트`)로 구분한다.
- 끝에 어떤 캡처를 어느 위치에 넣으면 좋을지 한 줄로 제안한다.

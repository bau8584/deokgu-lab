# 포트폴리오 페이지 작업 지침

"이 앱들 모아서 포트폴리오 페이지 만들어줘 / 갱신해줘" 요청을 받으면 수행한다.

## 결과물 형태
- **단일 HTML 파일**(`index.html`). CSS·JS 인라인. Cloudflare Pages에 그대로 배포 가능.
- 외부 의존성 최소화(폰트만 CDN 허용).

## 데이터 소스 — 자동 수집
- `shots/` 아래 각 앱 폴더를 훑어, 대표 썸네일(주석본 `-annotated.png` 우선,
  없으면 첫 캡처)과 `copy.md`의 **블로그 버전**을 카드 내용으로 가져온다.
- 앱별 링크는 폴더의 메타나 사용자 입력에서 받는다. 없으면 비워두고 보고한다.

## 레이아웃 — 카드 그리드 (확정)
- 반응형 카드 그리드(`repeat(auto-fit, minmax(240px, 1fr))`).
- 카드: 썸네일(위) + 제목 + 한 줄 소개 + "써보기" 링크 버튼.
- 상단 헤더: 워드마크 "박덕구쌤" + **치즈냥 짝꿍 아이콘(중간 노출)** + 태그라인
  "만드는 재미로 사는 초등쌤, 박덕구".

## 디자인 — 치즈 팔레트 (확정)
- 배경 크림 `#FFF7EC`, 카드 흰색 계열, 텍스트 차콜 `#2E2A26`.
- 강조(버튼·링크·헤더 포인트) 치즈 오렌지 `#F2A33C`, 포인트 민트 `#3CC9A0`.
- 둥근 모서리, 부드러운 그림자. 폰트는 둥근 산세리프(제목)+가독성 산세리프(본문).
- 모바일에서 1열로 자연스럽게 무너지게.

## 규칙
- 새 앱이 `shots/`에 추가되면 **카드 한 장만 더**하는 방식으로 갱신(전체 재생성 지양).
- 사실만. `copy.md`에 없는 기능을 지어내지 않는다.
- 완성 후 파일 경로를 안내하고, 배포 전 점검 포인트(링크·이미지 경로)를 한 줄로 보고한다.

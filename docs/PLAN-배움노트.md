# PLAN 배움노트 연재 (2026-10-03, [덕구랩] 새기능: 배움노트 연재)

## 독자·목적
- 독자: AI로 뭔가 만들어 보고 싶은 동료 교사(+비개발자 일반인).
- 목적: "비개발자 교사가 AI와 만들며 실제로 뒤집힌 판단" — 사건·판단·한 줄 원칙.
- 이건 아님: 성과 자랑·강의 광고. 포트폴리오 효과는 따라오는 것.

## 원재료 → 글
- 원재료 = `hq/learn/` 주제 파일의 **긴 절**(이미 씀 → 새 의무 없음). 1편 = 같은 주제 긴 절 1~3개 묶음.
- 바꾸는 것: 근거(파일 경로·커밋) 삭제 · 내부 숫자는 이해에 필요한 것만 · 앱 이름은 쉬운 말("모임 게임 앱")
- 공개 전 점검: 학생 이름·반·번호·학교명·수익/겸직 같은 신상 얘기 grep + 소유자 육안.
- 초안은 `webs/note-<영문>/index.html`. 홈 카드는 소유자 OK 뒤(그 전엔 링크 없음 = 숨김). 팁 판정 글과 같은 방식.
- 꾸준히 = 정해진 요일 없음. `/hq 마감` 때 새 긴 절이 생기면 "글감 됐어요" 한 줄.

## 끝 기준
1. 연재 순서표(아래)가 있다.
2. 1편 초안이 로컬 미리보기에서 열리고, 점검(이름·학교명) 통과.
3. 홈 카드·필터 붙이기는 소유자 OK 뒤.

# 뀨 캐릭터 디자인 브리프 (이미지 생성 AI / 일러스트레이터용)

## 1. 실제 뀨 특징 (레퍼런스 — 사진 함께 첨부)
- 연한 크림빛 치즈 태비 (진한 주황 아님, 창백·부드러운 주황)
- **투톤이 핵심:** 등·머리·꼬리 = 주황 / 턱·가슴·배 = 흰색, **앞발은 흰 양말**, 주둥이 흰색
- 핑크 코, **초록빛 큰 눈**
- 이마 M자 줄무늬 + 얼굴 줄무늬, 꼬리 링무늬
- 복슬복슬 중장모, **통통(돼냥)**, 둥근 얼굴·볼살
- 성격: 돼냥(통통 느긋) + 개냥(사람 좋아하는 헤벌쭉)

## 2. 목표 스타일
- 가나디풍 한국 이모티콘: 미니멀·헐렁·"살짝 성의 없어 보이는" 선, 플랫 컬러
- **귀여움 원리 (기괴함 방지 핵심):**
  - 눈을 크게, **얼굴 아래쪽(중앙선 아래)에 배치**
  - 이마 넓게, 코·입은 작게·낮게·서로 가깝게
  - 귀는 작고 둥글게 (뾰족·높으면 기괴해짐)
  - 머리 크게(대두), 몸은 둥근 청크 덩어리
- 한눈에 성격이 읽히게

## 3. 브랜드 팔레트
- 몸(주황): `#F2A33C` / 흰 부분: `#FFF7EC` / 외곽선: `#2E2A26`
- 포인트 민트: `#3CC9A0` (덕구랩=Lab 상징, 작은 플라스크 소품)
- 코: 연핑크

## 4. 필요 세트 (이모티콘/스티커)
기본 · 윙크("사실 저예요") · 개냥 헤벌쭉(혀) · 돼냥 식빵 · 작업중(민트 플라스크) · 뿌듯 · 놀람
→ **투명 배경**, 통일된 라인·컬러.


## 6. 추천 경로
- 사진→귀여운 캐릭터엔 **image-to-image 지원 이미지 생성 AI**가 최적
  (구글 Gemini 이미지, ChatGPT 이미지, Midjourney 등). 한국 이모티콘 제작 서비스도 있음.
- 스티커 세트 완성 후 → SVG/PNG로 받아 로고·페이지·인스타에 적용.
- 벡터 로고 마크(단순 심볼)만 따로 필요하면 그건 SVG로도 가능.

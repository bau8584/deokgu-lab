## Part 2. 인디스쿨 반응 분석 (냉철하게)

**잘 터지는 공식 = 보편적 교사 고통 + 즉시 사용 + "10초컷/5분/한방" 시간절약 프레임.**
- 근거: evalBee 204, 카훗 153, 교우관계 그래프 101, 컬투쇼 100.

**저조한 것 = 체육 니치 도구 + 인터랙티브 웹앱 + 아주 최근 글.**
- 체육 점수판 8, 발야구 20. 인디스쿨은 '다운로드 파일' 문화라 *설치·접속형 웹앱*에 덜 반응.

**시사점**
- 직접 만든 웹툴 중 검증된 승자는 **교우관계 그래프(101♥)** — 보편·감정적 고통을 데이터로 푼 것.
- 배드민턴 리그·점수판 같은 인터랙티브 웹앱은 인디스쿨보다 **인스타 릴스(화면녹화)**가 무대.

## Part 3. 게시 전략

### 원칙 (브랜드 정합)
- 배달부 자세: 선물처럼 툭, 무료·바로 씀. 자기홍보 톤 자제.
- 화력 집중: 첫 공개는 *가장 검증된 + 즉시 쓸모있는 하나*로.
- 닉네임: 인스타/페이지=덕구랩 / 인디스쿨=`박덕구 | 덕구랩`(이력 보존).
- 9:1: 완성품 위주, 비하인드는 가끔. 개인용(음주일기)은 공개 제외.

### 현장별 첫 타자 (데이터 기반)
- **인디스쿨 → 디지털 교우관계 그래프.** 이미 101♥ 검증 + 보편·감정적 고통 + "한 방에 해결" 프레임.
  덕구랩 서명 달고 재공개(업데이트판) 또는 신규 도구로 이어가기.
- **인스타 → 배드민턴 리그 / 체육 점수판.** 움직이는 화면녹화 릴스로. 치즈냥 화자.
- **배드민턴 카페·동호회 → 배드민턴 리그 웹.**

### 게시 순서 (제안)
1. **홈 먼저:** 포트폴리오 최소 버전으로 도착지 확보(현장 글은 휘발성).
2. **인디스쿨 1발:** 교우관계 그래프(선물처럼) → 반응·검증 수집.
3. **반응 좋으면:** 인스타에 웹앱 데모 릴스 + 다음 도구.
4. **배드민턴 현장:** 리그 웹 별도 공개.

### 인디스쿨 게시글 틀
1. 훅 — 공감 교실 문제 2. 이거 만들었어요(무료) 3. 스샷 2~3장 4. 링크+"가져다 쓰세요" 5. 덕구랩 서명만 살짝

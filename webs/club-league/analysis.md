# club-league (배드민턴 클럽용 리그) 분석

> 데모 리그(가짜 닉네임)로 로그인 후 전 화면 확보 완료. 아래는 실제 확인된 기능.

## 메이저 기능
- **티어 순위표** — 순위·급(A급/조심 등)·닉네임·티어·RP·최근 5경기·승률을 한 화면에. 경기 결과가 쌓이면 티어·랭킹 자동 갱신. (히어로 화면)
- **경기 기록 입력(복식 2:2)** — 동호회 주력인 복식용 2:2 스코어보드. 팀 나눠 점수만 올리면 바로 랭킹 반영.
- **매치 추천(AI)** — 선수 선택 후 '✨신선한 파트너' 추천. 실력 비슷한 파트너·상대로 새 조합·팽팽한 대진.
- **오늘의 경기(일별 요약)** — 날짜별 총경기·참여 인원·단복 비율·최다승 요약. 학교판과 차별되는 동호회 포인트.
- **구글 소셜 로그인 + Supabase 백엔드** — 진입은 구글 계정 로그인. 리그 안쪽은 회원 전용 폐쇄 구조.

## 운영·관리 기능
- **회원 관리** — 닉네임·레벨·나이·성별·티어·RP 인라인 편집 + 명단 붙여넣기 대량 등록.
- **휴면 감점(클럽 전용)** — 안 나온 회원 티어별 RP 차감(골드/플래티넘/다이아 각 10RP). 감점 실시·내역. 티어가 살살 내려가 자연스러운 복귀 유도.
- **시즌 관리** — 새 시즌 시작 시 RP 1000점 초기화, 명단은 유지. (데모: 시즌2·경기8·참여9)
- **데이터 관리** — 전체 리그 JSON 백업/복원. 총무 교체 시 파일 하나로 통째 인수인계.
- **관리자 글로벌 설정** — 경기 입력 방식(관리자만/자율/완전자율) + 리그 이름.
- **RP 커스터마이즈** — 보너스 점수(오늘의 첫 승·복수전 성공 등), 페널티, 티어 세부 설정(티어별 기준점·승/패 RP).
- **화면 테마 4종** — 게임·블랙·모던·클레이.

## 개발자 의도
school-league(학교용)의 동호회(교실 밖) 버전. 브랜드가이드상 "배드민턴 동호회 = 교실 밖 현장, 메이커-우산 정체성의 증거". 총무가 순위·대진을 엑셀·수기로 관리하던 반복 노동을 자동화("번거로움 제거")하고, 티어·랭킹·휴면감점으로 경기 기록을 데이터화·게임화("개념의 데이터화")하는 것이 목표. 사람이 얽힌 판(다인 시스템)을 굴리는 걸 지향한 작품.

## 독자 니즈
- **동호회 총무·운영진**: 정모마다 순위표·대진 손집계, 명단·인수인계 관리 반복 노동을 덜고 싶다.
- **동호회 회원**: 티어·랭킹이 실시간으로 보이면 정모 참여 동기부여(게임화).
- **초등교사(동아리·스포츠클럽 운영)**: 방과후·스포츠클럽 리그에도 같은 마찰 → 교실 밖으로 확장되는 도구.

3. "총무 바뀌어도 JSON 파일 하나로 통째 인수인계."

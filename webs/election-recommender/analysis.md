# 전교임원선거 추천인 관리 시스템 — 분석

앱명(내부): "학생회 추천인 명부" · Google Apps Script 웹앱

> 소유자 명시 허가로 관리자(데모 비번)와 후보/추천 흐름 안쪽을 **직접 확인**함(2026-07).
> 관리자 요약 화면에 실제 학생명이 섞여 있어, 캡처 시 예시 후보(홍길동) 외 실명은 **블러 처리**.
> 파괴적 조작(삭제·초기화·설정 변경)은 하지 않음 — 보기·캡처만.

## 메이저 기능
- **후보 자가 등록** (확인) — 후보 학생이 직접 학년·반·번호·이름·출마 직위·로그인 비밀번호를 입력해 등록. 학년을 고르면 그 학년의 출마 직위(예: 6학년 회장/부회장)가 동적으로 뜸. 종이 명부 없이 링크로 시작.
- **추천 받기 / 추천인 명단 자동 수집** (확인) — 후보 대시보드의 "추천 받기" 화면에서 기기를 추천 학생에게 건네주면, 추천 학생이 본인 학년·반·번호·이름을 입력하고 손글씨 서명("✍️ 추천인 이름 직접 쓰기")까지 남겨 추천인으로 등록. "같은 자리에선 한 후보에게만 추천 가능" 안내로 중복 추천 차단. 후보별 추천인 명단이 자동으로 쌓임.
- **실시간 목표 진행률** (확인) — 관리자 요약 화면에서 후보별로 "N / 목표" 진행바가 실시간으로 채워짐(예: 1/30, 0/30).
- **관리자(교사) 집계·검토·다운로드** (확인) — 관리자 로그인 후 요약/검토/반별 현황/설정 4개 탭. 요약 탭은 직위별로 후보를 묶어 진행률과 함께 표시하고 **엑셀·PDF 다운로드** 버튼 제공. 반별 현황 탭은 학년→반을 골라 그 반 학생들의 추천 내역을 번호순으로 조회(전체 추천 엑셀 다운로드 포함).

## 마이너 기능
- 후보 로그인 / 로그아웃 (확인)
- 비밀번호 찾기·재설정 안내 (확인 — "비밀번호를 잊어버렸어요" + 관리자가 설정 탭에서 분실 안내 문구 편집)
- 부정 추천 방지 안내 + 정직 서약 체크박스 (확인) — "거짓 추천 시 후보 자격 박탈, 반별 검증" 경고.
- 관리자 최초 비밀번호 설정 화면 (확인 — 첫 진입 시 setup, 이후 로그인 폼)
- 관리자 설정 (확인) — 직위별 목표 인원, 추천인 학년 범위, 출마 직위 생성/삭제, 추천 제한 규칙(자리마다 1명/역할마다 1명/학년마다 1명/전체 1명) 선택.
- 손글씨 서명(추천인 이름 직접 쓰기) (확인 — 추천 화면 버튼)
- 후보 삭제 (추정 — 미확인. 파괴적 조작이라 시도 안 함)
- 검토 탭 상세 (추정 — 후보 미선택 시 "불러오는 중"만 확인, 내용 진입 안 함)

## 개발자 의도
종이로 돌리던 전교임원선거 추천인 명부를 디지털화. 핵심은 (1) 후보가 스스로 등록, (2) 추천 학생이 기기 하나로 본인 정보+서명을 남겨 **명단이 자동 집계**, (3) 교사는 손으로 세지 않고 반별로 검증·다운로드만 하는 흐름. "거짓 추천 방지·반별 검증" 문구가 반복되는 걸 보면 대필·도용 같은 선거 공정성 문제를 특히 신경 쓴 설계.

## 독자(교사) 니즈
- 선거철마다 추천인 명단을 종이로 받아 **일일이 세고 대조하는 노동**을 줄이고 싶다.
- 추천인이 실제 본인이 맞는지(대필 아닌지) **검증 가능한 근거**(서명·반별 대조)를 원한다.
- 후보별 추천인 수가 정족수를 넘겼는지 **한눈에** 보고 싶다.
- 결과를 엑셀/PDF로 뽑아 결재·보관하고 싶다.

## 후킹 후보 3개
1. "전교임원선거 추천인, 아직도 종이로 세세요?" — 손집계 → 자동집계 대비.
2. "추천인 명단, 링크 하나로 저절로 모입니다." — 기기 건네주면 서명까지 받는 흐름.
3. "이 추천, 진짜 본인 맞아? — 반별로 검증되는 추천 명부" — 공정성 앵글.

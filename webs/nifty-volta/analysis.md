# nifty-volta — 체육관 교구 지도 대시보드 분석

앱: https://bau8584.github.io/nifty-volta/
다크테마 모바일-퍼스트 대시보드. 상단 학교명(개인정보→블러). 탭 3개: 가이드 / 교구 지도 / 행정 지원.

## 메이저 기능
- **교구 지도(2.5D 입체 보관지도)**: 체육창고를 3D 입체/2D 평면으로 보여주고, 구역(가·나·다·라·무대·조정실 등) 셀 그리드에 교구를 연동. "축구공, ㅋㅂ, ㅊㄱ"처럼 초성/부분 검색으로 어디 있는지 즉시 찾음.
- **체육관 보관 교구 전체 목록(75개)**: 영역(뉴스포츠·경쟁·도전·건강·전통놀이·PAPS 등) + 물품명 + 보관구역 + 수량을 한 목록으로. 구글 스프레드시트 4개 열과 실시간 동기화.
- **구글 시트 연동(맵·목록 데이터 소스)**: 2.5D 보관지도와 교구 목록이 "체육관 물품 장부" 구글 시트(관련영역·물품명·수량·보관장소 가/나/다/라·비고+약도)에서 생성 — 관리자가 시트만 고치면 반영, 코딩 없이 유지보수.
- **행정 지원**: 비품 파손/정비 요청, 교구 구매 희망 리스트, 행정 요청 코멘트 현황판을 폼으로 접수·집계. 구글 시트/Apps Script로 실시간 기록(미설정 시 LocalStorage).

## 마이너 기능
- 현재 체육관 수업 상태(방과후 공석 등 실시간)와 창고·공 보관함 상태 카드.
- 교구 사용법 가이드: 샤오미 전동식 공기펌프 2세대(종목별 권장 PSI 표), 접이식 웨건 사용/보관법.
- 체육관 금일 사용 시간표(교시별 학급·활동·완료 상태).
- 큰 글씨 토글(1.3x), 스마트 관리자 콘솔(시트 연동 설정), 전자호각·타이머(1/3/5분) 오버레이.
- 학생 단독 출입 금지 안전 배너.

## 개발자 의도
개발자 학교의 체육 교구 관리를 통째로 디지털화. 종이 장부·머릿속 위치기억에 의존하던 창고 관리를 "검색 가능한 지도 + 실시간 시트 연동 + 행정요청 창구"로 바꿔, 체육부장/체육 담당 교사의 반복 업무(교구 위치 찾기, 재고 파악, 파손·구매 요청 취합)를 줄이는 것이 핵심.

## 독자(교사) 니즈
- 체육 담당/체육부장: "그 교구 어디 있더라"로 창고를 헤매는 시간, 재고를 손으로 세는 수고를 줄이고 싶다.
- 교구 파손·부족을 발견해도 어디에 어떻게 요청할지 창구가 없어 방치되던 것을 폼 하나로 정리.
- 여러 교사가 함께 쓰는 체육관이라 "지금 비었나", "오늘 시간표"를 한눈에 알고 싶다.

## 후킹 후보 3개
1. "그 교구 어디 뒀더라?" — 창고 뒤지는 시간 vs 검색 한 번. (채택)
2. "교구 75개, 머릿속 장부는 이제 그만" — 재고·위치를 지도 하나로.
3. "파손 신고할 데가 없어서 그냥 넘어갔죠?" — 행정 요청 창구를 폼으로.

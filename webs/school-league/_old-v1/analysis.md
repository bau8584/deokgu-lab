## 메이저 기능
- **티어·RP 랭킹 시스템** — 순위표에 순위·학년/반·이름·티어(브론즈~다이아)·RP 점수·최근 5경기 W/L·승률이 표시된다. 3연승 뱃지 등 상태 표시도 있음. 티어 게임처럼 실력을 시각화. (10-tier-ranking.png)
- **경기 기록 입력** — 단식/복식 전환, 선수 A vs B 선택, +1/+5/+10·-1/-5/-10 버튼과 0 초기화가 있는 스코어보드로 즉석 채점. (11-record-input.png)
- **AI 매치 추천** — 선택한 선수 기준으로 매칭 범위(우리 반·다른 반·다른 학년)를 정하면 AI가 라이벌 #1·#2를 추천하고, 예상 RP 변동(승 +52 / 패 -55 등)까지 미리 보여준 뒤 "이 선수와 경기하기"로 바로 시작. (12-match-ai.png)
- **DIVISION UP(경기 결과 정산)** — 경기가 끝나면 승자/패자의 RP 변동, 승급/강등, 획득 보너스·차감 페널티 상세를 게임 결과 화면처럼 연출한다(예: 승자 +52RP 플래티넘 승급 / 패자 -71RP). (13-division-up.png)
- **교사 관리자 패널** — 화면 잠금(순위표·관리자 탭을 리그 코드로 잠금 — 태블릿을 학생에게 넘길 때), 리그 글로벌 설정, 학생 등록(나이스 명렬표 대량등록), 학생 관리, 리그 기록 관리, 데이터 관리(JSON 백업/복원), 시즌 관리, 리그 이름 설정. (14-admin-lock.png)

## 마이너 기능
- **순위표 필터** — 학년(전체~6학년), 티어(다이아~브론즈), 성별(남자/여자 순위) 필터. (10)
- **화면 잠금** — 순위표·관리자 탭을 4자리 리그 코드로 잠가, 태블릿을 학생에게 맡겨도 기록 입력만 열어둘 수 있음. (14)
- **나이스 명렬표 대량등록** — 학생 등록을 나이스 명렬표로 한 번에 처리. (14)
- **JSON 백업/복원** — 데이터 관리에서 리그 데이터를 JSON으로 다운로드·복원. (14)
- **시즌 관리** — 시즌 초기화 및 신규 시즌 생성. (14)
- **티어 세부 설정** — 기준점 프리셋(단기-촘촘 등)·승/패 RP 프리셋, 티어별 기준점(브론즈0/실버900/골드1050/플래1200/다이아1380)과 승리 +RP·패배 -RP를 직접 조정. (15-settings-tier.png)
- **보너스 점수 설정** — 오늘의 첫 승, 복수전 성공, 언더독 격파(티어 차), 신선한 매치, 연승 행진, 명승부 보너스. (16-settings-bonus.png)
- **페널티 설정** — 오만함의 대가, 굴욕적 완패, 복수 허용, 챔피언의 무게, 연패의 늪, 스포츠맨십 위반(레드카드). (17-settings-penalty.png)
- **구글 소셜 로그인 · Supabase 백엔드** — 로비의 구글 로그인 단일 진입 + Supabase 통합. (01-lobby.png)
- **학생 관리** — 나이스 명렬표 대량등록, 명단표에서 RP 직접 수정·삭제, 삭제한 학생 복원. (18-member.png)
- **시즌 관리(시즌제)** — 현재 시즌·경기수·참여 학생 확인, 새 시즌 시작 시 전원 1000RP로 초기화하되 학생 명단은 유지. (20-season.png)
- **데이터 백업/복원** — 데이터 관리에서 전체 리그를 JSON으로 통째 내보내기, 파일 업로드로 롤백 복원. (21-backup.png)
- **화면 테마 4종** — 게임·블랙·모던·클레이 테마를 팝오버에서 선택, 교실 분위기/취향대로 화면 톤 변경. (theme-picker.png)

## 개발자 의도
- **체육 리그를 티어 게임처럼** — 단순 기록이 아니라 티어·RP·승급/강등·보너스/페널티로 아이들의 참여 동기를 게임처럼 끌어올린다. DIVISION UP 연출·3연승 뱃지가 그 증거.
- **교사 운영 자동화** — 순위·대진을 손으로 관리하던 부담을, 나이스 대량등록·JSON 백업·시즌 관리·AI 매치 추천으로 자동화. 화면 잠금은 태블릿을 학생에게 넘기는 실제 교실 상황을 배려한 설계.
- **커스터마이즈 지향** — 티어 기준점·보너스·페널티를 프리셋과 표로 조정할 수 있어, 학급·기간·수업 목적에 맞게 리그 규칙을 재단.

## 독자(교사) 니즈
- 순위표를 칠판/종이로 손수 갱신하던 수고를 줄이고 싶다.
- 승패가 티어에 바로 반영돼 아이들이 다음 경기를 기대하게 만들고 싶다.
- 태블릿 하나로 굴리되, 학생이 관리자 화면은 못 건드리게 하고 싶다.
- 명단 등록·백업 같은 운영 잡무를 최소화하고 싶다.

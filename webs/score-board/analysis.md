# 점수판 웹 — 분석 노트

## 메이저 기능
- **큰 2팀 점수판**: 빨강/파랑 두 팀의 점수를 화면 가득 크게 표시. 태블릿을 그대로 코트 옆 전광판처럼 쓰는 컨셉.
- **탭으로 점수 증가**: 각 팀 영역을 탭하면 점수 +1. − 버튼으로 감소, ↺ 초기화 버튼으로 리셋.
- **다양한 종목 모드**: 일반 점수판 / 세트 카운터 / 타이머 사용 / 야구 / 발야구 / 킨볼. 한 앱에서 종목만 바꿔 쓴다.
- **설정 모달(⚙) 커스터마이즈**: 팀 색상(빨강·파랑·초록·노랑·보라·주황 중 선택), 팀 이름 직접 입력.

## 마이너 기능
- 야구/발야구 표시 항목 토글: 스트라이크·볼·아웃·파울 표시 여부 선택.
- 킨볼 옵션: 목표 점수(기본 13), 시간 제한(분·초) 설정.
- 일반 점수판 내 세트 카운터 토글, 타이머 사용 토글.
- 테마 전환: 다크 / 화이트.

## 개발자 의도
- 교실·체육관에서 종목이 바뀔 때마다 앱을 갈아끼우지 않도록 "한 판으로 다 되는" 점수판을 지향.
- 멀리서도 보이는 대형 표시 + 탭 한 번 조작으로, 수업 중 교사가 기록에 매이지 않게 하려는 마찰 제거형 도구.
- 색·이름 커스터마이즈로 우리 반 팀 편성에 그대로 붙게.

## 독자(교사) 니즈
- 체육 시간에 점수 세다가 헷갈리거나, 학생들이 "우리 몇 점이에요?" 계속 묻는 상황을 줄이고 싶다.
- 종목마다 다른 앱·화이트보드·손기록을 오가는 번거로움을 없애고 싶다.
- 태블릿 한 대만 세워두면 되는, 설치·계정 없는 가벼운 도구를 원한다.

## 종목별 기능
직접 확인한 각 모드의 화면 동작.
- **일반 점수판**: 화면을 좌(빨강팀)·우(파랑팀)로 나눠 큰 숫자로 점수를 표시. 팀 반쪽을 탭하면 +1, 각 반쪽의 − 버튼으로 감소, 하단 `↺ 초기화`로 리셋.
- **세트 카운터**: 일반 점수판 위에 가운데 작은 "세트 0 : 0" 패널이 뜬다. 세트 단위 승수를 별도로 센다(세트 선승 판수 설정과 연동).
- **타이머**: 상단 가운데에 `0:00` 시간 표시가 붙는다. 카운트업/카운트다운/현재시간 중 선택. 세트 카운터와 동시에 켤 수 있다.
- **야구**: 상단 "1회 초" 회차 표시, 가운데 세로 OUT 표시(점 3개), 하단 컨트롤바에 S(스트라이크·점 3), B(볼·점 4), F(파울·숫자) 칩과 `⇄ 공수 전환`, `📋 기록`, 경기 초기화 버튼. 경기 시작 시 "먼저 공격할 팀을 선택하세요" 선공 선택 오버레이가 뜬다. 공격팀은 진하게, 수비팀은 흐리게 표시.
- **발야구**: 야구와 같은 보드를 쓰되 표시 항목을 발야구용으로 전환(설정에서 스트라이크·볼 등 항목을 껐다 켰다 하여 발야구에 맞게 구성). 회차·공수 전환·기록·OUT 등 야구 골격은 동일.
- **킨볼**: 화면을 3등분(3팀). 각 팀 위에 목표 점수만큼의 pip(동그라미)이 있어 점수가 오르면 채워진다. 각 팀 아래 −/+ 버튼. 상단 가운데 `점수제 / 시간제` 전환 세그먼트와 "1세트 · 3판 선승" 포맷 표시.

## 설정창 항목 상세
설정(⚙) 모달에서 직접 확인한 항목.
- **팀 A / 팀 B**: 각각 색상(빨강·파랑·초록·노랑·보라·주황 6색 스와치, 이미 쓰는 색은 taken 처리) 선택 + 팀 이름 텍스트 직접 입력.
- **일반 점수판 카드**: `세트 카운터` 토글, `타이머 사용` 토글. 타이머를 켜면 카운트업 / 카운트다운 / 현재시간 하위 선택이 나타난다.
- **야구 점수판 표시 항목 카드**: `야구` / `발야구` 전환 버튼 + `스트라이크`·`볼`·`아웃`·`파울` 각각 표시 토글.
- **킨볼 카드**: 점수제 `목표 점수`(기본 13), 시간제 `제한`(분·초) 입력, `세트 선승(판)`, `시간제 알림음` 토글.
- **테마 카드**: 🌙 다크 / ☀️ 화이트.
- **점수 카드**: `점수 초기화`(위험 버튼).
